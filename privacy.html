Gizlilik Politikası / Privacy Policy

Son güncelleme / Last updated: 4 Kasım 2026

Türkçe

YT Otomasyon ("Uygulama"), YouTube kanalı yönetimini otomatikleştirmek için Google OAuth ve YouTube Data API kullanır.

  • Erişilen veriler: Yalnızca izin verdiğiniz kapsamlar (ör. YouTube kanal bilgileri, video yükleme ve düzenleme).
  • Kullanım: Veriler yalnızca sizin başlattığınız işlemleri (video yükleme, başlık/açıklama güncelleme vb.) gerçekleştirmek için kullanılır.
  • Saklama: OAuth erişim belirteçleri yalnızca uygulamanın çalıştığı cihazda saklanır. Kişisel veriler sunucuya kaydedilmez, satılmaz veya üçüncü taraflarla paylaşılmaz.
  • İzni geri alma: Erişimi istediğiniz zaman Google Hesap İzinleri sayfasından kaldırabilirsiniz.

Uygulamanın Google API'lerinden alınan bilgileri kullanımı, Sınırlı Kullanım gereksinimleri dahil olmak üzere Google API Hizmetleri Kullanıcı Verileri Politikası'na uygundur.

English

YT Otomasyon ("the App") uses Google OAuth and the YouTube Data API to automate YouTube channel management.

  • Data accessed: Only the scopes you grant (e.g. YouTube channel info, uploading and editing videos).
  • Use: Data is used solely to perform actions you initiate (uploading videos, updating titles/descriptions, etc.).
  • Storage: OAuth tokens are stored only on the device running the App. Personal data is not stored on servers, sold, or shared with third parties.
  • Revoking access: You can revoke access at any time at Google Account Permissions.

The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
